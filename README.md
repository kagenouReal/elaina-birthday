# Elaina Birthday

A small birthday page for Elaina, made by Kagenou. It has an opening screen, a few notes and wishes, and a gallery of illustrations from Majo no Tabitabi.

The site is built with React, TypeScript, and Vite.

## Run locally

Requires Node.js and npm.

```sh
npm i
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
